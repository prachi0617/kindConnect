# KindConnect User Registration Starter

This project includes only user registration for KindConnect.

Files:
- User.java
- UserRepository.java
- RegisterRequest.java
- AuthResponse.java
- AppConfig.java
- AuthService.java
- AuthController.java
- HomeController.java
- application.properties
- pom.xml
- TERMINAL_COMMANDS.md

Run:

```bash
mvn spring-boot:run
```

Register API:

```text
POST http://localhost:8080/api/auth/register
```
